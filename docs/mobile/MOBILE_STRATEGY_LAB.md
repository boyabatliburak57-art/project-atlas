# Mobile Strategy Lab

The iOS Strategy Lab is an owner-scoped research workspace, not an execution or investment-advice product. It reuses the server Strategy and Scanner AST contracts; mobile never accepts SQL, arbitrary expressions, or unsupported rules. Editing creates an immutable revision and historical runs retain their original revision.

The primary surface contains strategies, recent backtests, bounded experiments, methodology, and provider status. Production without authoritative market data fails closed with `PROVIDER_REQUIRED`. Development evidence is visibly marked `DEMO_UI_FIXTURE` and `NOT_LIVE_OR_PRODUCTION_MARKET_DATA`.

Accessibility contracts include labelled revision/rule groups, AND/OR semantics, Dynamic Type, 48-point controls, non-colour states, disclosures, and chart summaries. Manual VoiceOver remains `ACCEPTED_PRODUCT_WAIVER / OPEN_TASK_100K`.
