# Atlas Mobile Design System

Mobile v1 validates the standard iPhone profile. Small/large iPhone, Android and tablet native validation is deferred to v1.1. Tablet tokens and responsive
primitives are preserved for v1.1 experimentation and are not production evidence.

Direction: professional financial application, premium fintech, trustworthy and data-focused.
Chatbot, prompt, AI avatar/sparkle, gamified trading and recommendation language are prohibited.

Tokens live in `@atlas/design-tokens`: semantic light/dark surfaces, financial states, 12-step
spacing, responsive widths, system typography, tabular numerals, 48px targets and reduced motion.
Components consume semantic tokens; financial direction always combines sign/arrow, text and an
accessible label. Borders and spacing precede shadows. API freshness and client cache staleness are
different concepts.

Motion is limited to navigation, sheets and material state transitions. Haptics are adapter-owned
and limited to material selection/success/warning/refresh events.
