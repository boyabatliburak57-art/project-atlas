# Mobile Portfolio Transactions

Supported records follow the backend contract: BUY, SELL, DIVIDEND, CASH_DEPOSIT, CASH_WITHDRAWAL, FEE, TAX, transfers and approved adjustments. UI wording is “Alış/Satış kaydı ekle”; no execution CTA exists. Canonical decimal strings are sent to the server. Backend ledger projection and cost-basis policy are authoritative. Posted/system records preserve audit history through correction or reversal; corporate-action records cannot be silently deleted.
