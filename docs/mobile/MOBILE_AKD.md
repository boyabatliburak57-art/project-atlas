# Mobile AKD

AKD labels its temporal field “İşlem Tarihi” and explains “Kim alıp satıyor?”. Symbol/institution modes share query primitives. 1D/5D/20D controls use actual sessions, ranked rows use tabular numbers, and authoritative arithmetic stays server-side.

The surface exposes buyers, sellers, all institutions, bounded history, status, coverage, and the `institutional-net-flow-v1` methodology. It never renders AL/SAT advice.
