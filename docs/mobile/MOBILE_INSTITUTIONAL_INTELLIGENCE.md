# Mobile Institutional Intelligence

Canonical ownership is Markets → Institutional. The compact local navigation is Overview, AKD, Takas, and Institutions. Money Flow is contextual and no bottom tab or tools wall is added.

The first viewport shows one data-status strip, a bounded flow summary, top buyer/seller rows, and three focused entry points. Submodules load on entry. Provider-required, license-required, delayed, stale, partial, no-data, and unresolved states are distinct. Signed numbers include text and direction, not color alone.
