# Atlas Mobile Accessibility Foundation

Interactive targets are at least 48×48. Text scales and wraps; system fonts and tabular numerals
are used. Decorative icons are hidden, while meaningful icons have labels. Selected, disabled,
expanded and error states are semantic. Finance changes include arrow/sign, text and spoken label.

Modal/sheet implementations must move focus into content and restore it on dismissal. Charts
require a textual summary. Forms associate error text with fields. Reduced motion disables
nonessential animation. Phone/tablet focus order follows visual reading order. TASK-100K owns full
VoiceOver, TalkBack, contrast and device certification.
