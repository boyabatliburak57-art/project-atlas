# Mobile Takas

Takas labels its temporal field “Takas Tarihi” and explains “Paylar kimde tutuluyor?”. It exposes current distribution, largest holders, increases/decreases, bounded trend, source-classified foreign holdings, and freshness.

Unsupported values use an em dash. Foreign classification is never inferred. Charts and lists are progressively disclosed, bounded, accessible, and subject to cache/export/share license restrictions.
