# Mobile Symbol Detail

Symbol Detail maps the existing profile, quote, chart, fundamentals and pattern contracts to native
iOS surfaces. Overview is eager; Financials, Patterns, Insights and Company are lazy capability
surfaces. Missing values remain unavailable/not-evaluable and are never rendered as zero.

Share payloads contain only symbol, company, allowlisted Atlas deep link and disclosure. Watchlist
and alert actions remain unavailable TASK-100F links. Company URLs require credential-free HTTPS.
Patterns retain state, cutoff, methodology and no-look-ahead disclosure and are never labelled as
investment recommendations.
