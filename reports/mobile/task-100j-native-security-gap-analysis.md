# TASK-100J Native Security Gap Analysis

Date: 2026-08-09  
Scope: iOS phone v1 (`iPhone 17`, `iOS 26.5`)  
Source task: the TASK-100J specification supplied in the task request; the repository task copy was absent at audit start.

| Area                  | Current State                                                                       | Sensitive Data                         | Native Risk                                                           | Missing Control                                           | Required Test                                | Action                          |
| --------------------- | ----------------------------------------------------------------------------------- | -------------------------------------- | --------------------------------------------------------------------- | --------------------------------------------------------- | -------------------------------------------- | ------------------------------- |
| Session storage       | `ExpoSecureStore`, this-device-only accessibility                                   | AUTH_SECRET                            | Keychain items can survive reinstall independently from sandbox state | Installation marker and reinstall-safe purge              | Session storage inspection, reinstall policy | HARDEN                          |
| Query cache           | TanStack Query, memory-only, private keys owner-scoped                              | USER_PRIVATE, FINANCIAL_SENSITIVE      | Cross-user memory reuse if cleanup regresses                          | Central owner cleanup contract                            | Logout/user-switch isolation                 | HARDEN                          |
| Persistent bulk cache | No Query/AsyncStorage/SQLite persistence                                            | USER_PRIVATE, FINANCIAL_SENSITIVE      | Offline convenience could introduce unprotected persistence later     | Explicit deny-by-default classification/TTL policy        | Storage policy, secret scan                  | DOCUMENT_AND_ENFORCE            |

| App lifecycle         | Foreground callback only                                                            | FINANCIAL_SENSITIVE, AUTH_SECRET       | App-switcher snapshot can expose a protected screen                   | Privacy cover, centralized state/listener ownership       | Background/foreground native contract        | IMPLEMENT                       |
